方式二 · 书签一键抓取

在已登录的 ChatGPT 页面点一下书签，会自动读取当前 /api/auth/session 并跳回本页完成导入。

抓取 ChatGPT 登录态
  1. 把左边按钮拖到 Chrome 书签栏（或复制脚本，新建书签粘贴到网址栏）。
  2. 打开 chatgpt.com 并确认已登录。
  3. 点这个书签，页面会跳回管理台并自动导入。

原理：书签在 chatgpt.com 页面里读取你自己的 session，把数据放在本页地址的 #import= 片段里跳回当前管理台，数据只发给本管理台，不经过第三方。

关于地区价

  • 结账页的币种/价格由 IP 区域 + 账号账单地区共同决定，换 IP 后需要重新打开订阅页才会刷新。
  • 机房 IP 会被 ChatGPT 当成 VPN 拦截；用动态住宅渠道，地区尽量与卡的账单国家一致。
  • 「每个连接都换 IP」会让同一结账流程出现多个 IP，Stripe 容易风控，只建议用来测试。

说明

使用方法和注意事项。

购买链路

选 Plus/Pro → 订阅弹窗（已选中）→ 立即购买 → Stripe 结账页
   → 填卡（取卡库）→ 展开账单地址 → 填地址 → 提交订阅（真实扣款）

安全

  • 只监听 127.0.0.1；token 与卡信息都存在本机 data/，文件权限 0600。
  • 管理台不会自动帮你点「提交订阅」，必须手动确认金额。
  • 卡号在界面上默认打码，只有主动点「复制」才会解密展示。
  • 同一时刻只能登录一个账号（cookie 是浏览器配置级的）。

常见问题

  • 登录失败：session 被踢下线，回 ChatGPT 重新导出或再用书签抓一次。
  • 结账页没出来：点「去结账」后等 20–40 秒；被 Cloudflare 拦时重试即可。
  • 提交后被拒：Stripe 返回的原文会显示在抽屉里，按提示换卡或核对地址。
  • 兑换卡住：到「兑换记录」看客户那笔卡在哪一步、报错原文和当时的页面截图。
